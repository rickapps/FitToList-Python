FitToList User Guide

FitToList helps you crop, straighten, and resize a whole folder of photos quickly. Work through your source images one at a time, editing each and saving it into a separate processed folder.

1. Select your folders

File > Select Folders... opens a dialog for choosing both:

  • Source — the folder containing your original images.
  • Processed — where edited copies are written. This cannot be the same folder as Source.

The file list on the left shows every source image, with any processed versions already saved for it nested underneath. Selecting either loads it into the editor.

2. Crop

Drag anywhere on the image to draw a crop selection. Once drawn, you can:

  • Drag an edge or corner to resize it.
  • Drag inside it to move it without resizing.

While a selection is active, the status bar shows its size in image pixels. Use Actions > Crop to Selection to apply it, or just double-click inside the selection to crop and save in one step.

3. Straighten

Use Actions > Straighten to fix a slightly crooked photo — a tilted horizon, for example — without the limitation of the 90°-only Rotate commands.

  1. Starting Straighten draws a level line across the image, with a draggable handle at each end.
  2. Drag either end (up to 30° in either direction) to line it up with a tilted feature in the photo. The image itself doesn't move while you drag — only the line — so you can align it precisely by eye.
  3. Releasing the drag rotates the image immediately. The line reappears level so you can drag again to fine-tune.
  4. When you're done, click anywhere else on the image, click the Straighten button again, or press Esc to dismiss the line.
Straighten never crops the image for you. Rotating exposes blank corners, which are filled in white (or left transparent). Follow up with Crop to Selection to trim them, and run Straighten again if 30° wasn't enough correction.

4. Rotate and flip

CommandEffect
Actions > Rotate Right / Rotate LeftRotates the image 90° at a time.
Actions > Reverse ImageFlips the image horizontally (mirror image).

5. Reset

Actions > Reset discards every edit made since the image was loaded and restores it exactly as it was read from disk.

6. Save

  • File > Save writes your edits to the processed folder.
  • Actions > Process & Save saves and then automatically advances to the next unprocessed source image — the fastest way to work through a whole folder.

Saving a source image always writes a new file (never overwriting the original), named name_00.ext, name_01.ext, and so on. Reopening one of those processed files and saving again overwrites it in place instead, with a confirmation prompt if you have unsaved changes.

7. Max Save Size

File > Max Save Size... (or the link in the top bar) sets an optional maximum width and height applied only when saving. Oversized images are shrunk to fit, preserving aspect ratio; images are never enlarged. This never changes what's shown on screen — only the saved file. When set, it's shown in the top bar and reflected in the status bar's "Save size."

8. Reduce All Images

File > Reduce All Images batch-processes the whole source folder in one step — handy for quickly getting a folder of camera photos ready for use on a web page, without opening and saving each one by hand.

  • Every image in the source folder is copied to the processed folder. Any image larger than the current Max Save Size is shrunk to fit (preserving aspect ratio); images already within that size are copied unchanged.
  • Copies are named with the same name_00.ext, name_01.ext auto-numbering as a regular Save, so running it more than once just adds another set of copies instead of overwriting earlier output.
  • The file list updates as each image finishes, so you can watch its progress.
Reduce All Images requires a Max Save Size to be set first — see Max Save Size above. If none is set, you'll be prompted to set one before it will run. A confirmation dialog explains what's about to happen before any files are written.

Unsaved changes

If you try to switch images or folders while you have an uncommitted crop selection, a pending Straighten, or unsaved edits, FitToList asks whether to save, discard, or cancel — so you won't lose work by accident.
